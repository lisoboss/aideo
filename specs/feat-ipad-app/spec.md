# feat-ipad-app

> 最后更新：2026-07-02（v2 — 画布中心化重构）

## 背景与目标
> iPad 端 AI 视频生成工作站。以**画布为中心**，节点化工作流（ComfyUI 启发但非照搬），支持多项目管理。所有创作、生成、预览、下载均在一张自由画布上完成。

## 核心概念

### 画布即一切
不再有"创作/历史/下载"分页。每个项目 = 一张自由画布（灵感板），画布上放置各种节点，节点间可选连线表示关系/流程。

### 节点类型

| 节点 | 说明 | 状态 |
|------|------|------|
| **提示词卡片** | 7 种类型（场景/角色/动作/风格/镜头/氛围/自定义），可拖拽、编辑、连线 | 已有 |
| **媒体输出节点** | 显示生成的视频/图片，可预览播放，可下载/分享。**生成按钮在此节点上** | 新增 |
| **参考素材节点** | 从相册/文件导入的图片/视频，连线到提示词卡片提供视觉参考 | 新增 |
| **AI 增强节点** | 输入简单描述 → LLM 输出详细提示词，连线到提示词卡片 | 新增 |

### 生成流程
```
提示词卡片 ─╮
参考素材 ───┼──→ 输出节点 [生成] ──→ 视频/图片出现在输出节点中
AI 增强 ───╯
                        ↑
              流程进行到的节点高亮
```

- 用户连接提示词/参考/AI 节点到输出节点
- 点击输出节点上的"生成"按钮
- 当前正在处理的节点高亮显示
- 完成后视频/图片直接出现在输出节点中，可预览/播放/下载

### 参数
生成参数（时长/分辨率/风格/seed）内嵌在提示词卡片中，不独立为节点或面板。

## 侧边栏

```
┌─────────────┐
│ Aideo       │
│ ─────────── │
│ 🎬 赛博短片  │  ← 多项目列表
│ 🌅 风景集锦  │
│ 🐱 猫咪视频  │
│             │
│ [+ 新建项目] │
│             │
│ ⚙️ 设置     │
│ ● 已连接    │
└─────────────┘
```

- **项目列表**：多个画布项目，点击切换
- **新建项目**：创建空白画布
- **项目操作**：长按/右键 → 重命名、复制、删除
- **连接状态**：底部显示后端连接指示灯

## 用户故事
- 作为创作者，我希望在画布上自由排列提示词、参考图、AI辅助节点，用连线组织创意流程
- 作为创作者，我希望在输出节点上直接预览生成的视频、一键下载
- 作为创作者，我希望管理多个灵感板项目，不同项目互不干扰
- 作为创作者，我希望看到生成流程中哪个节点正在被处理（节点高亮）
