# 剧情模型

## 主线目标树

```text
最终方向：在玩家降临与四国战争前建立不可替代的优势
├── 生存：控制邪能腐化，避免恶魔身份暴露
├── 成长：牧师主线、死亡术士副主线、战斗副职业
├── 资源：知识、卷轴、经验、装备、资金、亡魂
├── 身份：牧师、情报人员、黑帮打手、双面交易者
└── 势力：教会、黑帮、自由之誓、紫川国安局、神选者
```

## 八个剧情单元

### 单元一：幽灵船与双职业起点（第一至第十章）

- **触发**：沈生穿越到偷渡船，原身身份和游戏时间点被确认。
- **危机**：污染鱼缸把死者转化为幽灵，船上人员即将团灭。
- **选择**：沈生激活邪能求生，却暂不选择虚空职业，避免失去正常主职业。
- **转折**：他利用艾文的善意和圣物完成牧师前置任务，再选择死亡术士作为第二主职业。
- **结果**：危机解除，但他保留污染鱼缸并制造邪念集合体，主动背上更大的腐化风险。

### 单元二：雾隐镇落脚与资源闭环（第十一至第十六章）

- 出售幽灵材料获得启动资金。
- 接入灰隼的自由之誓情报据点。
- 借曹旺进入黑帮圈，以治疗换取暗网账号和职业知识。
- 学会自然愈合，建立“治疗获得经验、伤员提供收入”的资源循环。

### 单元三：刺杀阴谋与黑帮洗牌（第十七至第二十五章）

- 阿奎与外帮勾结，试图借庄严暗杀沈生。
- 庄严误入灰隼据点，被灰隼击杀。
- 沈生在宴会上揭穿阿奎，以邪念集合体完成处决。
- 他购买仿生拟态面具，化身赌徒“孙洋”参与帮派火拼，获得黑帮打手副职业。

### 单元四：多方结盟与斧头帮覆灭（第二十六至第三十七章）

- 斧头帮依附更强势力，正面行动受阻。
- 沈生用牧师身份经营各区关系，用孙洋身份制造战果。
- 他以声东击西和多方牵制完成围剿，自己单人击穿斧头帮总堂。
- 黑帮线完成从“借势自保”到“能够左右地区格局”的升级。

### 单元五：沼泽巨鳄与邪念集合体晋升（第三十八至第四十三章）

- 李现为异能进化，坚持猎杀重伤的第二阶层巨鳄。
- 团队火力失败，沈生暴露暗影潜行和强力幽灵的部分能力。
- 沈生因同伴选择自我牺牲而没有撤退，放出邪念集合体反杀巨鳄。
- 邪念集合体晋升，沈生获得巨额经验和装备收益，但秘密暴露面扩大。

### 单元六：离开雾隐镇（第四十三至第四十四章）

- 沈生达到见习牧师成长瓶颈，需要转职卷轴。
- 艾文提供顾清风推荐信，沈生回赠神圣系职业知识。
- 灰隼将虚构的神选者情报上报，为沈生在翠玉城建立任务身份。
- 雾隐镇阶段以资源、人脉和情感关系全面结算。

### 单元七：翠玉城报到冲突与双面布局（第四十五至第五十四章）

- 沈生在入城事故中救下紫川国安局刺刀小队成员。
- 顾清风因其学习暗影知识拒绝直接给转职卷轴，善意安排反而堵住沈生原计划。
- 沈生向自由之誓情报站报到，被猫头鹰、渡鸦压制，当场杀死麻雀和鹦鹉立威。
- 他借快递员身份秘密接触紫川国安局，以自由之誓情报换牧师资源。
- 双方都在监视治疗店；沈生利用三花猫、暗语和表演，在渡鸦眼前完成交易。

### 单元八：抚伤者转职与落凤峡谷新局（第五十五至第五十六章）

- 紫川国安局交付治疗系转职卷轴，沈生转职为抚伤者。
- 他继续欺骗猫头鹰，制造神选者正式接触的假象。
- 沈生选择孙莹莹同行前往磐石公司，准备利用其心灵能力和国安身份。
- 落凤峡谷、秘密实验室、腐烂巢穴和孙莹莹体内异常共同构成下一阶段入口。

## 关键因果链

```text
污染鱼缸制造幽灵
→ 沈生被迫使用邪能
→ 需要牧师力量净化腐化
→ 经营艾文关系并获得双职业
→ 保留鱼缸制造邪念集合体
→ 获得远超同级的战斗与升级能力
→ 能介入黑帮和大型怪物事件
→ 声望与资源增长
→ 进入翠玉城多方情报博弈
→ 用情报交换转职资源
→ 准备渗透腐烂巢穴
```

## 当前未闭合剧情线

- 孙莹莹身上的猩红娜迦之毒及情绪异常。
- 神选者首领明镜与磐石公司的真实组织状态。
- 落凤峡谷秘密实验室中的腐烂巢穴与绿色宝石。
- 猫头鹰、渡鸦是否会识破沈生的假接头。
- 紫川国安局准备如何使用沈生提供的情报。
- 顾清风是否会获知沈生真实的暗影与邪能路线。
- 艾文及“原历史圣骸”命运是否已被彻底改写。
- 玩家内测将在数月后到来，沈生造成的蝴蝶效应会如何影响历史。
- 邪能腐化虽然暂时可控，但沈生尚未取得净化之息所需的全部基础知识。
