# 影视化建模建议

## 最适合先做的短片单元

### 方案一：幽灵船求生

- **覆盖**：第一至第三章，可压缩为 3–5 分钟概念短片。
- **核心看点**：脏乱封闭船舱、幽灵屠杀、系统接驳失败的喜剧反转、邪能首次爆发。
- **角色**：沈生、幽灵、偷渡客群体；艾文只需在结尾出现。
- **优势**：场景集中、目标明确、视觉冲击强，容易验证世界观和主角气质。

### 方案二：牧师与恶魔的第一次合作

- **覆盖**：第七至第九章。
- **核心看点**：沈生表演舍己、艾文交出圣物、圣光与邪能同场、邪念集合体诞生。
- **优势**：最能表达作品独特命题，并建立沈生与艾文关系。

### 方案三：影帝式谍战接头

- **覆盖**：第四十九至第五十四章。
- **核心看点**：快递争吵掩护接头、猫咪敲暗码、两方监视、渡鸦毫不知情。
- **优势**：低成本城市场景即可完成，黑色喜剧和信息差突出。

## 角色视觉锚点

| 角色 | 必须稳定的视觉元素 | 可随身份变化的元素 |
|---|---|---|
| 沈生 | 东方青年、警觉目光、偶尔露出的暗绿腐化纹理 | 帽子、面具、牧师袍、运动装、黑帮疤脸 |
| 艾文 | 金发、碧眼、年轻、纯净圣光 | 牧师袍细节与成长后的庄重程度 |
| 灰隼 | 邋遢中年、酒瓶、疲惫感 | 出手瞬间的锐利姿态和银色左轮 |
| 邪念集合体 | 绿色雾状人形、多张痛苦面孔 | 体型、触手、实体化程度 |
| 孙莹莹 | 高马尾、利落身形、强观察感 | 作战服、便装、都市约会装 |
| 渡鸦 | 表面憨厚与瞬间阴狠的反差 | 快递／保镖伪装、暗夜行者状态 |

## 主角表演规则

沈生应始终有“两层表演”：

1. 镜头内其他角色看到的表情与语言。
2. 观众通过内心旁白、系统画面或细节特写知道的真实计算。

如果只拍外层，他会像传统圣人；如果只拍内层，他会像单纯反派。两层并置，才形成原作的黑色喜剧和角色魅力。

## 镜头语言建议

- 圣光：稳定构图、柔和暖白、缓慢推进，强调秩序和安全。
- 邪能：不稳定构图、暗绿脉动、局部变形、低频噪声，强调诱惑和失控。
- 身份切换：通过帽子、面具、服装和姿态完成匹配剪辑。
- 信息差喜剧：让观众先看到沈生的准备，再切到对手自信判断，最后用一个反应镜头完成反转。
- 系统信息：只显示当前剧情必要的少量字段，避免把画面变成大段游戏说明。

## 一致性检查项

- 当前场景中哪些角色知道沈生是牧师、间谍或幽灵操控者？
- 沈生此时是否已经学会对应技能？
- 腐化程度是否与此前邪能用量一致？
- 邪念集合体当前等级和形态是否符合章节时间点？
- 艾文对沈生的信任程度是否匹配关系进展？
- 镜头是否把“角色误解”错误地表现成客观事实？
- 改编是否保留了主角在利益计算之外偶尔出现的真实善意？
