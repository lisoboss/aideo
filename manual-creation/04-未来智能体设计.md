# 未来智能体设计

本文件记录从手动流程演进到人工智能导演智能体时的初步构想，不代表当前已经进入实现阶段。

## 智能体的职责

未来的导演智能体主要负责：

1. 理解用户当前想完成或修改什么。
2. 读取项目材料，判断下一步应该询问、规划还是调用生成能力。
3. 只在高影响且低置信度的创作决策上询问用户。
4. 调用大语言模型、视频生成和素材生成工具。
5. 保存用户确认后的结果。
6. 在设定变化后找出受影响的剧本、素材和镜头。

## 建议维护的结构化状态

- 故事圣经：主题、世界观、人物、关系、场景和视觉基调
- 剧情节拍表：剧情节拍、转折、高潮和收束
- 镜头计划：镜头时长、画面、动作、声音、提示词和素材引用
- 导演决策：待用户确认的关键决定、候选项及影响
- 修改依赖图：设定与剧本、素材、镜头之间的依赖关系

## 推荐演进方式

先使用单个导演智能体作为编排者，把 `aideo-runtime` 的能力封装成可调用工具。手动流程中稳定、重复且有明确输入输出的步骤，再逐个交给智能体。

```
读取项目状态
  → 判断缺失信息或下一步行动
  → 询问用户或调用工具
  → 校验输出
  → 写回已确认状态
  → 标记受影响内容
```

## 初始动作集合

为了保证行为可控，智能体的动作可先限制为：

- 询问用户
- 提出故事候选方案
- 生成剧情节拍
- 生成镜头计划
- 生成素材
- 渲染预览
- 查找受影响镜头
- 精修镜头

## 从手动流程中获取的依据

未来是否自动化一个步骤，应以手动执行记录为依据：

- 输入和输出是否稳定
- 判断标准是否能够明确描述
- 错误是否容易发现和恢复
- 是否会大范围影响后续内容
- 是否必须由用户表达创作意图

高影响且难以恢复的决定继续保留用户确认；机械、重复、可回滚的工作优先自动化。
