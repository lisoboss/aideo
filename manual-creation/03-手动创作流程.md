# 手动创作流程

## 总体流程

```
创作输入
  → 创意会谈
  → 故事与人物设定
  → 剧本和剧情节拍
  → 角色、场景与道具素材
  → 分镜计划
  → 完整低清预览
  → 镜头级修改与精修
  → 成片
```

## 1. 接收创作输入

允许从任意成熟度开始：

- 一句话故事灵感
- 故事梗概
- 完整剧本
- 已有角色、场景或其他素材

手动整理输入，区分用户已经确定的事实、偏好以及仍可自由创作的部分。

## 2. 创意会谈

使用大语言模型生成少量有明显差异的故事方向，并说明每个方向对人物、冲突、情绪和结局的影响。

用户确认关键选择后，将结论写入创意简报。未确认的模型输出不能直接成为后续生成依据。

## 3. 建立故事与人物设定

整理故事主题、世界规则、人物关系、角色目标、主要场景和视觉基调。它们构成后续创作的一致性依据。

如果输入已经是完整剧本，这一步仍然需要执行，用于抽取并固定剧本中的隐含设定。

## 4. 形成剧本和剧情节拍

由大语言模型将已确认方向整理为适合 1–3 分钟短片的剧情结构，再细化为可执行剧本。

人工重点检查：

- 开场是否快速建立人物与情境
- 冲突是否清楚
- 转折是否有铺垫
- 结局是否回应主题
- 时长是否合理

## 5. 建立素材库

先生成角色、场景和关键道具的参考素材。用户选定的素材被标记为正式参考，后续镜头生成优先复用。

同一角色的外观、服装和显著特征应有明确记录；场景也应固定时间、天气、空间关系和色彩基调。

## 6. 制作分镜计划

由大语言模型把剧本拆成镜头。每个镜头至少记录：

- 镜头编号和对应剧情段落
- 预计时长
- 画面内容与人物动作
- 景别、机位和运镜
- 台词、旁白或声音要求
- 使用的角色、场景和道具素材
- 视频生成提示词

人工确认镜头是否必要、前后是否连贯，以及总时长是否满足目标。

## 7. 生成完整低清预览

逐镜调用视频生成服务，使用较低成本参数快速获得全部片段，然后按分镜顺序拼接。

这一阶段主要验证：

- 故事能否看懂
- 节奏是否自然
- 人物和场景是否连续
- 情绪是否符合预期
- 关键镜头是否有效

## 8. 镜头级修改与精修

问题应落实到具体镜头或具体设定。修改角色、场景或剧情事实后，人工检查所有受影响镜头，而不是只修改当前片段。

确认镜头后再使用高质量参数生成。单镜头通过后锁定，避免后续操作无意覆盖。

## 9. 完成成片

所有镜头锁定后进行最终拼接，补充配音、音乐、音效、字幕和必要的转场，并保存输出版本与修改记录。

## 手动阶段需要记录的数据

每次执行流程时，应保留：输入内容、模型请求、模型输出、用户选择、修改原因、使用的参考素材、生成参数和最终结果。这些记录将决定未来智能体能自动化哪些步骤。
